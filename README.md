# AI Knowledge Assistant

A production-style AI assistant built using OpenAI, RAG, Redis, ChromaDB and React.

## Features

- Streaming Responses (SSE)
- Conversation Memory
- Redis Cache
- Vector Search (ChromaDB)
- Retrieval Augmented Generation (RAG)
- Context Compression
- Source Attribution
- React Chat UI

## Tech Stack

Backend:
- Node.js
- TypeScript
- OpenAI
- Redis
- ChromaDB

Frontend:
- React
- Vite

## Run Locally

### Backend

npm install
npm run dev

### Frontend

npm install
npm run dev
